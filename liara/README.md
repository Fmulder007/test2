# LIARA — HTTP XSPF-каталог

Генератор создаёт один XSPF-плейлист для всей видеотеки `/data/video`.

## Что делает

- Рекурсивно обходит всю видеотеку, а не только отдельную папку.
- Сохраняет настоящую вложенность каталогов в дереве VLC.
- Включает пустые папки.
- Сначала показывает папки, затем медиафайлы — как в Проводнике.
- Добавляет аудио- и видеофайлы поддерживаемых расширений.
- Формирует прямые HTTP-ссылки через Nginx: `http://192.168.2.221/video/`.
- Корректно кодирует кириллицу, пробелы и специальные символы в URL.
- Не обходит символические ссылки.
- Записывает плейлист атомарно и не перезаписывает его, если содержимое не изменилось.
- Защищает генерацию от одновременного запуска.

**Важно:** скрипт только читает каталог и создаёт XSPF. Он не запускает, не останавливает и не управляет серверным VLC. В нём нет RTSP, VLM, `cvlc` или `daemon`.

## Пути

| Назначение | Путь |
|---|---|
| Видеотека | `/data/video` |
| Генератор | `/usr/local/sbin/liara-video-xspf.php` |
| Результат | `/usr/local/www/liara/video.xspf` |
| Адрес плейлиста | `http://192.168.2.221/video.xspf` |
| HTTP-адрес файлов | `http://192.168.2.221/video/...` |

## Установка в jail Liara

Команды выполняются на хосте FreeBSD через `jexec`.

```sh
jexec liara fetch -o /usr/local/sbin/liara-video-xspf.php https://raw.githubusercontent.com/Fmulder007/test2/main/liara/liara-video-xspf.php
jexec liara chmod 755 /usr/local/sbin/liara-video-xspf.php
```

## Создание или обновление плейлиста

Запустить вручную от root:

```sh
jexec liara /usr/local/sbin/liara-video-xspf.php
```

После выполнения открыть в VLC:

`http://192.168.2.221/video.xspf`

Генератор можно запускать повторно после добавления, удаления, переименования файлов или папок. Настройка cron не устанавливается автоматически.

## Требования к Nginx

В Liara уже используется HTTP-раздача:

```nginx
location ^~ /video/ {
    alias /data/video/;
    limit_except GET HEAD {
        deny all;
    }
}
```

Для работы XSPF автоиндекс каталогов не требуется. Достаточно, чтобы прямые URL файлов открывались по HTTP.

## Ограничения

- В плейлист попадают только файлы с поддерживаемыми аудио- и видеорасширениями, перечисленными в генераторе. Остальные файлы не становятся пунктами воспроизведения.
- Реальные каталоги сохраняются в дереве, в том числе пустые.
- Символические ссылки пропускаются.
- Имена с некорректным UTF-8 или управляющими символами пропускаются.
- Скрипт рассчитан на запуск внутри jail Liara от root.
