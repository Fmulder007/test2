# Подключение TALI к VLC

TALI отправляет VLC снимок выбранного плейлиста через локальный Telnet-интерфейс. VLC должен работать в jail `tali` и слушать только `127.0.0.1:4212`.

## Конфигурация на сервере

Создай файл `/usr/local/etc/tali-vlc/tali-api.php` внутри jail `tali` со следующим содержимым, указав тот же пароль, который передан VLC параметром `--telnet-password`:

```php
<?php
declare(strict_types=1);
return [
    'password' => 'ТВОЙ_ПАРОЛЬ_VLC',
];
```

Ограничь доступ к файлу и дай PHP-FPM (пользователь `www`) право чтения:

```sh
jexec tali chgrp www /usr/local/etc/tali-vlc
jexec tali chmod 750 /usr/local/etc/tali-vlc
jexec tali chown root:www /usr/local/etc/tali-vlc/tali-api.php
jexec tali chmod 640 /usr/local/etc/tali-vlc/tali-api.php
```

Сам файл не размещается в каталоге сайта и не попадает в Git.

## Работа

В открытом плейлисте появляется кнопка **«В эфир»**. Нажатие сохраняет существующий VLM-канал `tali` и его HTTP-выход, удаляет только прежние входы командой `setup tali inputdel all`, передаёт VLC все файлы в сохранённом порядке, включает повтор списка (`setup tali loop`) и переключает работающий канал на первый новый файл командой `control tali play 1`. Канал и HTTP-адрес `http://АДРЕС_СЕРВЕРА:8090/stream` не пересоздаются.

Отправленный список является снимком: последующие изменения плейлиста не меняют уже запущенный эфир. Повторное нажатие «В эфир» заменяет список входов и переключает воспроизведение на его первый файл без команды `stop`.

При нажатии «В эфир» браузер передаёт API ID элементов в текущем отображаемом порядке плейлиста. Поэтому сортировка по имени, дате или размеру определяет последовательность вещания; режим «Ручной порядок» отправляет сохранённую последовательность. API проверяет, что передан полный набор ID именно выбранного плейлиста. Временная сортировка не изменяет сохранённый порядок в базе.

Для работы VLC-пользователь должен иметь право чтения файлов в `/data/video`. Telnet VLC должен оставаться привязанным к localhost; открывать порт 4212 в сеть не требуется.
