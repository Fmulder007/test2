# GSSx11 — план разработки и дневник

## 1. Назначение

Самостоятельный скетч генератора на Si5351, созданный на основе проверенных компонентов GSSx10. GSSx10 остаётся нетронутым.

Основная задача: ручная установка частоты от **1 до 200 МГц** с выбором одного активного выхода CLK0, CLK1 или CLK2, настройкой шага энкодера и сохранением параметров во внутреннюю EEPROM микроконтроллера.

## 2. Зафиксированные решения

### 2.1. Аппаратная база и библиотеки

- Главный файл: `GSSx11.ino`.
- Дисплей: OLED 128×32 SSD1306, библиотека `GyverOLED.h` и шрифт `charMap.h` из GSSx10.
- Синтезатор: библиотека Si5351 `si5351a.h/.cpp` и низкоуровневый I²C-драйвер `i2c.h/.cpp` из GSSx10.
- Кольцевая память: `Block_Ring_EEPROM.h/.cpp` из GSSx10.
- Все восемь файлов библиотек скопированы в `GSSx11/` без изменения исходного содержимого. Исходники GSSx10 не изменяются.
- Для памяти используется только внутренняя EEPROM AVR с `BLOCK_INTERNAL`; библиотека сама определяет её полный размер через `E2END`.
- Сигнатура записей отдельная: `GSSx11`.
- Энкодер: A/B — D2/D3, кнопка — D4 с `INPUT_PULLUP`. Используется внешняя Arduino-библиотека `Encoder.h` (как и в GSSx10).
- OLED и Si5351 используют существующую I²C-шину. Другие GPIO проектом не настраиваются и не используются.

### 2.2. Экран

OLED: 128×32.

- Верхняя строка: частота размером шрифта 2, девять цифр в герцах с ведущими нулями: `007100000`, `200000000`.
- Нижняя строка: слева активный выход `CLK0/CLK1/CLK2`, справа шаг: `1Hz`, `10Hz`, `100Hz`, `1kHz`, `10kHz`, `100kHz`, `1MHz`, `10MHz`.
- Активное поле выделяется инверсией текста штатным `invertText()`.
- После успешной записи настроек во внутреннюю EEPROM весь дисплей инвертируется на 150 мс через `invertDisplay()`, затем возвращается к нормальному отображению.
- Фатальная ошибка памяти выводится одной строкой мелким шрифтом, например `[MEMORY ERROR #12]`.

### 2.3. Энкодер и переходы между полями

Начальное активное поле — частота.

1. Частота: вращение меняет её на текущий шаг; нажатие переводит к выбору шага.
2. Шаг: вращение циклически выбирает один из восьми шагов. Если итоговый шаг отличается от значения при входе в поле, следующее нажатие возвращает к частоте. Если шаг не изменился, нажатие переводит к выбору выхода.
3. Выход: вращение циклически выбирает CLK0 → CLK1 → CLK2 → CLK0; нажатие возвращает к частоте.

Кнопка: длительность измеряется между подтверждёнными антидребезгом нажатием и отпусканием. Если длительность меньше `ENGINEERING_MENU`, это короткое нажатие; если равна порогу или больше — длинное. Действие выполняется только при отпускании.

Шаги: 1/10/100 Гц, 1/10/100 кГц, 1/10 МГц, а также 1 кГц — всего восемь значений: 1, 10, 100, 1000, 10000, 100000, 1000000 и 10000000 Гц.

- Частота ограничивается диапазоном 1 000 000–200 000 000 Гц. За границами значение не зацикливается и не переполняется.
- Для настройки частоты и частоты кварца используется `ENCODER_COUNTS_PER_STEP`.
- Для выбора шага, выхода, реверса энкодера и мощности используется отдельный `ENCODER_MENU_COUNTS_PER_STEP`.
- Оба делителя по умолчанию равны 4 и настраиваются независимо.
- При настройке частоты каждое обнаруженное вращение обрабатывается по направлению: сначала частота округляется к ближайшей границе шага в сторону вращения; если значение уже кратно шагу, выполняется полный шаг. Величина накопленного `delta` не умножает частотный шаг. Логика повторяет подход `160x14`.
- Кнопка имеет программный антидребезг.

### 2.4. Управление выходами Si5351

- В каждый момент включён только один выбранный выход.
- CLK0: `si.set_freq(frequency, 0, 0)`.
- CLK1: `si.set_freq(0, frequency, 0)`.
- CLK2: `si.set_freq(0, 0, frequency)`.
- При смене выхода сначала вызывается `si.set_freq(0, 0, 0)`, чтобы выключить прежний CLK, затем включается выбранный выход на текущей общей частоте. Переход выполняется по принципу break-before-make.
- При изменении частоты обновляется только логически выбранный выход.
- Файлы `si5351a.cpp/.h` не изменялись.
- Для поддержки 200 МГц скетч использует открытые статические параметры библиотеки: `VCOFreq_Max = 900 МГц`, `VCOFreq_Mid = 800 МГц`. Это настройка из GSSx11, а не правка исходников драйвера. Делитель 4 позволяет получить 200 МГц при PLL 800 МГц.
- Частота опорного кварца задана константой `XTAL_FREQUENCY_HZ = 32000000` Гц — такое начальное значение использовалось в GSSx10.

### 2.5. Структура и начальные настройки

Сохраняется одна структура ровно из трёх полей:

- `uint32_t frequency` — частота в герцах;
- `uint8_t stepIndex` — индекс шага 0–7;
- `uint8_t outputIndex` — индекс выхода 0–2.

На целевой AVR-платформе размер структуры — 6 байт. Активное поле интерфейса и временные флаги в EEPROM не сохраняются.

Начальные значения для новой пустой EEPROM:

- частота — 7 100 000 Гц;
- шаг — 1 кГц (индекс 3);
- выход — CLK0 (индекс 0).

### 2.6. Сохранение настроек

- Записывать структуру только при наличии изменений относительно последней успешно сохранённой структуры.
- После последнего вращения или нажатия должно пройти не менее 5000 мс.
- Любая новая активность сбрасывает отсчёт.
- После успешной записи обновляется эталон сохранённых значений и один раз инвертируется весь дисплей на 150 мс.
- Не записывать EEPROM при каждом щелчке энкодера.
- Если пользователь вернул все значения к последней сохранённой комбинации, запись не требуется.

### 2.7. Обработка ошибок памяти

- Проверяется результат каждой операции `init()`, `read()` и `write()`.
- `BLOCK_RING_OK == 0` — успех.
- При любой фатальной ошибке OLED очищается, выводится только числовой код в формате `[MEMORY ERROR #N]`, после чего основная работа останавливается, сообщение остаётся на экране до перезапуска.
- Имена enum не расшифровываются. Отдельных таблиц, строковых описаний и изменений библиотеки для ошибок нет.
- Единственное исключение: если `read()` возвращает `BLOCK_ERR_READ_NO_RECORD` (17), это считается первым запуском с пустой EEPROM. Загружаются значения по умолчанию, выполняется первая `write()`, и её код обязательно проверяется.
- Если эта первая запись неуспешна, отображается её код и устройство останавливается.
- Любой другой ненулевой результат `init/read/write` фатален.
- Если запись прошла CRC-проверку, но содержит значения вне допустимых диапазонов, скетч показывает код 19 (`BLOCK_ERR_INVALID_ARGUMENT`) и останавливается.

## 4. Реализация

В первой реализации выполнено:

1. Подготовлена автономная папка GSSx11, библиотеки перенесены из GSSx10 без редактирования.
2. Реализована инициализация внутренней кольцевой EEPROM, восстановление настроек, первый запуск при коде 17 и аварийный экран с числовым кодом.
3. Реализованы частота, восемь шагов, выбор одного из трёх выходов и обновление Si5351.
4. Реализован экран OLED 128×32 с инверсией активного поля.
5. Реализованы переходы между полями и антидребезг кнопки.
6. Реализовано сохранение после 5 секунд бездействия, без лишних записей, с инверсией дисплея на 150 мс.
7. Остаются проверки компиляции на целевом AVR, проверка на реальном OLED/энкодере/Si5351 и измерение частоты на всех трёх выходах, особенно вблизи 200 МГц.

## 5. Контрольный список испытаний

- Первый запуск с пустой EEPROM: настройки по умолчанию записываются, генератор стартует.
- Повторное включение: все три параметра восстанавливаются.
- Ошибки init/read/write: на экране точный числовой код, зависание в аварийном режиме.
- Изменение шага и оба варианта выхода из поля шага.
- Циклический переход CLK0 → CLK1 → CLK2 → CLK0.
- Нижняя/верхняя границы частоты 1 и 200 МГц, попытка уйти за границы.
- Реальная частота и отсутствие одновременной работы двух выходов.
- Сохранение через 5 секунд после последней активности, перезапуск таймера при активности.
- Проверка всех восьми шагов.
- Проверка стабильности работы на длительном интервале.
