# GSSx11 — инженерное меню и сохранение настроек

**Статус:** реализация внесена в `main`. План соответствует текущему поведению прошивки.

## 1. Дефайны

В начале `GSSx11.ino`:

```cpp
#define SAVE_DELAY 5000UL
#define ENGINEERING_MENU 1000UL
```

- `SAVE_DELAY` — время без вращения энкодера на главном экране до общей записи настроек.
- `ENGINEERING_MENU` — длительность нажатия для входа в инженерное меню и выхода из него.

## 2. Структуры настроек

Инженерные настройки инициализируются значениями по умолчанию непосредственно в структуре:

```cpp
struct EngineeringSettings {
  bool reverseEncoder = false;
  uint32_t xtalFrequency = 32000000UL;
  uint8_t power = 0;
};
```

Настройки главного экрана остаются в отдельной `GeneratorSettings`.

## 3. Размещение во внутренней EEPROM

- Первые 16 байт внутренней EEPROM зарезервированы под инженерные настройки и маркер корректности.
- Инженерная структура начинается с адреса 4.
- Кольцевой памяти передаётся диапазон от `ENGINEERING_EEPROM_RESERVED` до `E2END`.
- В `Block_Ring_EEPROM.h` документирован уже существующий интерфейс `init(device, signature, startAddress, endAddress)`, позволяющий задать кольцевой диапазон.
- Алгоритмы кольцевой записи, CRC и поиска записи не меняются.
- При переходе со старой раскладки прошивка сначала читает прежнюю запись генератора, затем переключает библиотеку на новый диапазон.

## 4. Инженерное меню

Долгое нажатие энкодера на главном экране (1 секунда) открывает меню.

Три строки, шрифт 1, активная строка инвертирована:

```text
REV_ENC=NO
XTL=32000000
PWR=0
```

- Вращение меняет выбранное значение.
- Короткое нажатие переходит к следующей строке.
- Долгое нажатие возвращает на главный экран.
- В инженерном меню таймер сохранения не отсчитывается.

## 5. Настройки

### REV_ENC

- Значения `YES/NO`, по умолчанию `NO`.
- В меню меняется только поле инженерной структуры.
- Фактическое направление энкодера загружается в отдельную рабочую переменную один раз при запуске МК.
- Поэтому изменение реверса действует только после перезагрузки.
- Существующее поведение реверса в остальных пунктах меню сохраняется.

### XTL

- Значение по умолчанию — `32000000UL`.
- Шаг изменения равен текущему шагу частоты главного экрана.
- При каждом изменении немедленно вызывается `si.set_xtal_freq()`, затем пересчитывается текущий активный выход.
- Выбранные частота генератора, шаг и выход не сбрасываются.

### PWR

- Значения 0–3, по умолчанию 0.
- При изменении немедленно применяется к текущему активному выходу Si5351.
- Выбранный выход не переключается.

## 6. Флаг вращения и сохранение

Отслеживается **сам факт вращения энкодера**, а не изменение значений структур.

- Любое вращение на главном экране или в инженерном меню устанавливает общий флаг активности.
- В инженерном меню таймер не работает.
- Если энкодер вращали в инженерном меню, после выхода на главный экран запускается новый отсчёт `SAVE_DELAY`.
- Вращение на главном экране перезапускает отсчёт.
- Если флаг установлен и на главном экране прошло 5 секунд без вращения, сохраняются целиком обе структуры: `GeneratorSettings` в кольцевую область и `EngineeringSettings` в зарезервированную область.
- Никаких отдельных сохранений параметров нет.
- Если энкодер ни разу не вращали после включения/предыдущего сохранения, таймер не запускается и EEPROM не записывается.
- После записи флаг сбрасывается, таймер останавливается, дисплей кратко мигает.

## 7. Состояние главного экрана после выхода и после сохранения

После выхода из инженерного меню главный экран возвращается в обычное состояние:

- активен пункт частоты;
- изображение частоты инвертировано;
- частота, выбранный шаг и выбранный выход остаются прежними;
- последующее вращение меняет частоту с выбранным шагом на выбранном выходе.

После автоматического сохранения:

- активным пунктом снова становится частота;
- инверсия изображения частоты снимается;
- частота, шаг и выход не меняются;
- при следующем вращении энкодера обычная инверсия активного пункта сразу возвращается.

Инверсия после сохранения относится только к отображению активной частоты. Существующее поведение остальных пунктов меню не меняется.

## 8. Что не меняется

- Основной алгоритм генерации частоты.
- Логика выбора активного выхода.
- Выбранный шаг при входе/выходе из инженерного меню.
- Кольцевой алгоритм и CRC.
- GSSx10.
